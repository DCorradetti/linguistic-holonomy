# Contributing

Corrections, reproducibility reports, and carefully scoped extensions are welcome.

1. Open an issue describing the mathematical claim, script, detector, or recorded run involved.
2. Keep versioned manuscripts, certificates, and recorded runs immutable. Corrections require a new version or a new timestamped run.
3. Add or update a certificate when a mathematical claim changes.
4. Add tests for computational changes and run `python -m pytest -q`.
5. Record the exact command, environment, inputs, hashes, conclusions, and limitations for every new result directory.

Please distinguish clearly between proofs, numerical checks, empirical observations, and conjectures. A certificate supports a manuscript proof; it does not replace one.
